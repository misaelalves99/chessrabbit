# ChessRabbit Roadmap

ChessRabbit is focused on local-first chess analysis: strong engines, useful training views and simple Windows installation.

## Now

- Keep the Windows installer reliable and easy to download.
- Improve the first-run experience for new users.
- Polish Stockfish analysis, PGN import, game review and study workflows.
- Keep release assets GPL-compliant with source archives and checksums.

## Next

- Add a clearer Leela Chess Zero setup wizard.
- Add a branded app icon and signed Windows installer.
- Add real screenshots and a short demo GIF to the README.
- Add more engine comparison views with saved provenance.
- Improve opening study and spaced repetition flows.
- Add more troubleshooting docs for Windows, GPU engines and backups.

## Later

- Optional cloud sync without removing local storage.
- More import/export formats for chess tools.
- Starter reference/puzzle datasets with clear licenses.
- Better automation around release notes and checksums.

All core features should remain free to use. Paid-plan gates, subscription checks and license keys are out of scope for the community edition.
