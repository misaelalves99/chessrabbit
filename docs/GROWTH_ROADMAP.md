# Growth Roadmap

ChessRabbit is now a public community project with a Windows installer, source release archive and local engine support. Growth should come from making the project easy to try, easy to trust and easy to discuss.

## GitHub Presence

- Keep the README focused on download, screenshots, local-first benefits and engine support.
- Add real app screenshots and a short demo GIF after each visual polish pass.
- Keep Releases current with `ChessRabbit-Setup.exe`, source archive, Stockfish source archive and checksums.
- Add GitHub topics listed in [GitHub Repository Profile](GITHUB_PROFILE.md).
- Keep Discussions active with starter threads from [Discussion Starters](DISCUSSION_STARTERS.md).

## Product Polish

- Add a branded app icon.
- Sign the Windows installer.
- Improve first-run onboarding and engine setup.
- Add clearer Leela Chess Zero setup docs for CPU and GPU users.
- Improve backup and data migration documentation.

## Community Outreach

- Share the launch copy from [Launch Kit](LAUNCH_KIT.md).
- Post updates when releases add visible user-facing improvements.
- Ask users for screenshots, workflows and engine setup feedback.
- Keep feature requests public and small enough for contributors to pick up.

All features should remain available without subscriptions. Contributions should improve local use, interoperability and documentation.
