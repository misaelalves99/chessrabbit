# Community roadmap

- Reproducible release ZIPs and signed desktop installers.
- CI builds and smoke tests for the optional Lc0 CPU image.
- More examples for native GPU backends and multiple networks.
- Acknowledged job queues and recovery for interrupted reviews.
- Data import tools and openly licensed starter datasets.
- Engine comparisons with saved review provenance.

All features remain available without subscriptions. Contributions should improve local use, interoperability and documentation.
