# Discussion Starters

Create these starter discussions after Discussions are enabled. They make the repo feel active and give new users a place to talk.

## Welcome

Title:

```text
Welcome to ChessRabbit Discussions
```

Body:

```markdown
Welcome to ChessRabbit Discussions.

Use this space for setup help, engine questions, feature ideas and chess analysis workflows. If you find a reproducible bug, please open an issue with the bug report template.

Good first posts:

- What engine are you using?
- What would make ChessRabbit easier to install?
- What PGN review feature do you want next?
- Did Stockfish or Leela setup work on your PC?

Thanks for helping make ChessRabbit better.
```

## Engine Setup Help

Title:

```text
Engine setup help: Stockfish, Leela and custom UCI engines
```

Body:

```markdown
Use this thread for help with Stockfish, Leela Chess Zero and custom UCI engines.

When asking for help, include:

- Windows version
- ChessRabbit version or installer name
- Engine name and version
- CPU/GPU details if using Leela
- What you tried
- Screenshot or error message
```
