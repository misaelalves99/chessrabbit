# Community edition scope

Implemented: no payment routes, subscription checks or paid features; GPL-3.0 license; automatic local sessions; localhost Docker setup; selectable UCI profiles; Stockfish default; optional CPU Lc0 image; native Windows/GPU worker instructions; cache separation by engine/network; backend and UCI regression tests.

Not included: native desktop installers, packaged release binaries, bundled neural networks, preloaded reference/puzzle datasets, durable acknowledged job retries or GPU-enabled Docker images.

Validation commands are in [Development](DEVELOPMENT_GUIDE.md). Run [Local smoke tests](../scripts/smoke_local.py) after starting Docker.
