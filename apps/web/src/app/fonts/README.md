# Bundled fonts

The English interface uses Latin subsets of Archivo (variable weights 100–900),
Instrument Serif (400), and IBM Plex Mono (400, 500, 600). Other characters use
the system fallback fonts. `next/font/local` serves these files from the static
bundle; builds do not request fonts from Google.

The unmodified WOFF2 files were downloaded from the Google Fonts CDN on
2026-10-02. Copyright and license notices are included alongside the files.

Sources:

- [Archivo](https://github.com/google/fonts/tree/main/ofl/archivo)
- [Instrument Serif](https://github.com/google/fonts/tree/main/ofl/instrumentserif)
- [IBM Plex Mono](https://github.com/google/fonts/tree/main/ofl/ibmplexmono)

Font files retain their SIL Open Font License 1.1; ChessRabbit's GPL-3.0 applies
to the application code.
